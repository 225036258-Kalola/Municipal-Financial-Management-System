## Project Description

The Municipal Financial Management System (MFMS) is a C-based system developed to help a municipality manage important financial and administrative information. The system provides functions for managing employees, budgets, suppliers, assets and reports. It provides a simple menu-driven interface that allows users to enter, search, display and manage information.

## System Features

### Employee Management

* Add employees
* Display employee information
* Search for employees
* Calculate employee salary information
* Generate employee reports

### Budget Management

* Enter departmental budgets
* Enter expenditure
* Check remaining budgets
* Check whether expenditure is within budget
* Display budget information
* Identify departments that exceed their allocated budget

### Supplier Management

* Add suppliers
* Display suppliers
* Search for suppliers

### Asset Management

* Add assets
* Display assets
* Search for assets

### Reports

* Employee reports
* Budget reports
* Supplier reports
* Asset reports
* Assets by department

## Compilation Instructions

The system is written in C and can be compiled using GCC.

Open the project folder in the terminal and run:

```bash
gcc *.c -o municipal
```

If there are no compilation errors, the executable file `municipal` will be created.

## How to Run the System

After compiling the program, run:

```bash
./municipal
```

The main menu will be displayed. Select the required option by entering the corresponding menu number.
